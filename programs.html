TechBridge Programs

Practical programs that turn learning into real skills

TechBridge programs are designed to help learners move from learning to doing. Each program introduces you to practical skills through hands-on, project-based work, so you can see how what you learn is used in the real world.

Explore Data Analytics Explore Web Development

Program 01

Data Analytics

Working with data and extracting insights

The Data Analytics program introduces you to practical data analysis. You'll explore how to work with raw data, prepare it for analysis, and turn it into clear insights that support business decisions.

Apply for Data Analytics

Skills you'll be introduced to

Spreadsheet analysis

Using spreadsheets to organize, calculate, and explore data.

Data cleaning

Finding and fixing errors, gaps, and inconsistencies so data can be trusted.

SQL

Using a query language to retrieve and work with data stored in databases.

Data visualization

Presenting data as charts and visuals that are easy to understand.

Business-focused analysis

Using data to answer real business questions and support decisions.

Program 02

Web Development

Designing and building websites and web applications

The Web Development program introduces you to practical website development. You'll explore how web pages are structured and styled, how to add interactivity, and how developers manage their code while building real web projects.

Apply for Web Development

Skills you'll be introduced to

HTML

Structuring the content of web pages.

CSS

Styling pages and making layouts work on every screen size.

JavaScript

Adding interactivity and behaviour to websites.

Git/GitHub

Tracking changes to code and sharing projects online.

Building web projects

Bringing these skills together to create complete, working websites.
